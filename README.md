# EatEzy

Дневник питания для Android, простой как калькулятор. Сфотографировал еду — запись готова: КБЖУ, ингредиенты с граммовкой, витамины, минералы, аминокислоты, добавки.

- **ИИ по вашему ключу:** OpenRouter (список vision-моделей крупных провайдеров + Auto и Auto free) и Google Gemini (с пометкой бесплатных). Список моделей обновляется сам раз в 3 дня. Запасные модели срабатывают по очереди, если основная не ответила.
- **Штрихкоды:** сканер на телефоне (ML Kit) → Open Food Facts. Если товара нет или его цифры не сходятся (калории ≠ 4·Б + 4·У + 9·Ж), этикетку читает ИИ.
- **Health Connect:** шаги, сожжённые калории, вес.
- **Без сервера:** все данные на телефоне. Импорт экспорта Fud AI (JSON) без потерь, экспорт в тот же формат.
- Интерфейс на русском и английском.

## Установка

Скачайте `EatEzy-*.apk` из [Releases](../../releases/latest). Все сборки подписаны одним ключом, поэтому новая версия ставится поверх старой с сохранением данных. В приложении: Настройки → Обновления.

## Сборка

JDK 17, Android SDK (compileSdk 37), Gradle 9.9:

```
gradle :app:assembleDebug
```

Подпись: `keystore.file` и `keystore.password` в `local.properties` (локально) или секреты `KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` (GitHub Actions). Без них сборка получается неподписанной.

Тесты: `gradle :app:testDebugUnitTest`. `ScreenshotTest` рисует экраны в `app/build/screens`. Переменная `FUD_EXPORT` с путём к экспорту Fud AI добавляет проверку импорта на реальных данных.
